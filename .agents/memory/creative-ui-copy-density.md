---
name: Creative UI copy density
description: Product preference for translating repetitive feature copy into concise, visual cues.
---

Prefer short, action-oriented labels paired with familiar icons, artwork, or visual hierarchy over dense lists of feature descriptions.

**Why:** The creator wants AIMD to feel like a creative studio rather than a word-heavy product brochure, while retaining the important detail where users need it.

**How to apply:** On high-traffic mobile and membership surfaces, use a concise description plus a small number of icon-led benefit cues. Keep explanatory copy for consequential decisions, accessibility labels, errors, and legal terms.
