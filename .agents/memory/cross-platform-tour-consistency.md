---
name: Cross-platform tour consistency
description: How web onboarding and the mobile Dashboard tour should stay aligned.
---

Use the mobile Dashboard tour as the source of truth for the web onboarding tour's story, creator-inclusive language, and audience representation.

**Why:** A shared first impression avoids conflicting product messages and ensures creators across disciplines see themselves represented, regardless of platform.

**How to apply:** When changing either tour, keep the slide themes and audience coverage aligned while allowing each platform to retain controls and layout suited to its interface.
