---
name: Design exploration isolation
description: Protect the current app while comparing preview-only visual alternatives.
---

New visual concepts and design variations must remain in the isolated sandbox and on the shared Canvas board until the user explicitly approves integration.

**Why:** The user wants to preserve the established app layout in case the team dislikes the experiments.

**How to apply:** Keep the existing app and production routes unchanged while exploring. Present independently labeled alternatives together for comparison, then integrate only the approved direction into the existing app.
